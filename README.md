# paper-synthesizer

Point it at an arXiv ID; get a layered Markdown synthesis: what the paper is
about, the gap it addresses, its hypothesis, results, implications, and a
section-by-section reading guide.

Summaries are generated by **DeepSeek V4.1 Flash** (`deepseek-v4.1-flash`)
through an **OpenCode Go** subscription.

## Install

Requires Python 3.12–3.14. Python 3.15 is not supported yet: `zstandard` (via
`langgraph-checkpoint`) has no wheels for it.

```bash
pipx install .                 # recommended: puts `psynth` on PATH
# or, in a checkout:
py -3.14 -m venv venv && source venv/Scripts/activate
pip install -e ".[dev]"
```

Create a key at https://opencode.ai/console (OpenCode Go subscription) and put
it in `.env`:

```bash
cp .env.example .env
# then edit .env: OPENCODE_API_KEY=...
```

Optional overrides: `OPENCODE_MODEL`, `OPENCODE_BASE_URL`,
`PSYNTH_MAX_SECTION_CHARS`, `OPENCODE_SESSION` (a stable session id; one is
generated per run otherwise).

## Use

```bash
psynth 2608.27454 -o output
```

```
output/2608.27454/
├── 2608.27454.pdf
└── 2608.27454_synthesis.md
```

Check credentials before a run:

```bash
psynth --check
```

### Flags

| Flag | Purpose |
| --- | --- |
| `-o, --output DIR` | Root output directory (default `.`) |
| `--check` | Validate key + model access, then exit |
| `--all-sections` | Synthesize every section, not just the selected ones |
| `--max-section-chars N` | Truncate each section before prompting (default 24000, `0` = off) |
| `--resume` | Continue from `<id>.state.json`, skipping completed sections |
| `--verbose` | DEBUG logging |

### What it handles

- **arXiv metadata** comes from the Atom API, so titles, authors, and abstracts
  are canonical even when the LaTeX is macro-heavy.
- **Multi-file LaTeX** (`main.tex` + `\input{...}`) is inlined before parsing,
  with cycle and path-traversal guards.
- **PDF-only papers** fall back to text extraction (`pdfminer.six`) and heading
  heuristics; the frontmatter records `source: pdf-text`.
- **Throttling** is absorbed with bounded retries, `Retry-After` support, and a
  descriptive User-Agent. Archive extraction uses a scratch directory and
  `filter="data"`, and never deletes files it did not create.
- **Interruptions**: progress is checkpointed after each section; rerun with
  `--resume`. A failed run leaves the `.tex`/`.json`/state behind for debugging.

## Output

One Markdown file with YAML frontmatter:

```yaml
---
paper_id: "2608.27454"
title: "WikiSkill: ..."
authors:
  - "Liyan Tang"
arxiv_url: "https://arxiv.org/abs/2608.27454v1"
version: "v1"
source: "tex"          # or "pdf-text"
model: "deepseek-v4.1-flash"
generated_at: "2026-11-14T11:17:54+00:00"
sections_synthesized: 4
sections_available: 9
---
```

The body covers the abstract, overarching synthesis, knowledge gap, hypothesis,
results, implications, final running synthesis, per-section synthesis plus
remarks, and a list of sections that were not synthesized.

## How it works

| File | Purpose |
| --- | --- |
| `psynth.py` | CLI: fetch → parse → synthesize → save; fallback and resume logic |
| `fetchpaper.py` | Downloads with retries/UA; safe archive extraction |
| `arxivmeta.py` | arXiv Atom API metadata client |
| `texsource.py` | `\input` inlining, main-file discovery, PDF text + heading split |
| `parsejson.py` | LaTeX → JSON parser and markup cleanup |
| `synthesistools.py` | Pydantic models, LangGraph pipeline, LLM client, Markdown writer |

Pipeline: **Pass 1** overarching synthesis → **Pass 1.5** section selection →
**Pass 2** research analysis → **Pass 3** per-section synthesis with a running
synthesis. Pass 3 synthesizes only the selected sections unless
`--all-sections` is passed.

## Development

```bash
pip install -e ".[dev]"
pytest
ruff check .
```

Tests run offline: network calls are monkeypatched and the LLM is stubbed, so
no API key is needed and no tokens are spent.

## Provider notes

The Go lane asks clients to identify themselves with their own User-Agent and to
send a stable `x-opencode-session` header per conversation; both are set
automatically. Without the session header, direct calls fail with HTTP 400
`missing x-opencode-session`.

`deepseek-v4.1-flash` is a Chat Completions model (`/chat/completions`). GPT and
`*-codex` models on the same gateway use `/responses`, so a base-URL swap alone
is not enough to move to them. The Go lane is a subscription with monthly model
allowances; the Zen lane (`https://opencode.ai/zen/v1`) is pay-per-token.

## Troubleshooting

`ImportError: cannot import name 'ArgsKwargs' from 'pydantic_core._pydantic_core'`
(or any other missing symbol from a compiled package) means the virtualenv's
interpreter changed after packages were installed. Binary wheels are tied to one
Python version, so re-creating a venv over an existing one leaves them
unloadable. Delete and rebuild it:

```bash
rm -rf venv
py -3.14 -m venv venv
pip install -e ".[dev]"
```
